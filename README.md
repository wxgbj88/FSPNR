Run the FSPNR code with input parameters:  seq, R, Centrality, D, t
seq: original protein sequence
R: 1 or 2, stand for R1 or R2 relationship maps
Centrality: 'degree','eigenv','katz','pagerank', represent the four types of centrality metrics
D: embedding dimension of PJSD
t:embedding lag of PJSD

The .mat files are the FSPNR features with embedding dimension D=3, embedding lag t=1,
and the FSNPR features with parameter variations.
